# Integrações externas pendentes

Nenhuma destas integrações está implementada na Fase 1. Cada uma deve ficar atrás de uma interface no módulo respectivo para permitir trocar de fornecedor.

| Integração                     | Módulo                     | Fase    | Uso                                                             | Notas / candidatos a avaliar                                                                                                                                 |
| ------------------------------ | -------------------------- | ------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| OCR de documentos              | `dms`                      | 2       | Extracção de dados de facturas, DU, BL, CMR, cartas de condução | Serviço gerido (ex.: AWS Textract, Google Document AI, Azure Document Intelligence) ou Tesseract self-hosted; os ficheiros já ficam em MinIO por organização |
| Pagamentos                     | `fin`                      | 3       | Cobranças, escrow do marketplace, pagamentos a transportadores  | Multicaixa Express / EMIS (Angola), referências de pagamento, cartões internacionais; reconciliação bancária                                                 |
| SMS / WhatsApp                 | `iam`, `trk`, notificações | 2–4     | OTP/MFA, alertas de expedição, prova de entrega                 | Operadores angolanos (Unitel, Africell), agregadores, WhatsApp Business API                                                                                  |
| Mapas e geolocalização         | `tms`, `trk`               | 2       | Geocodificação, rotas, ETA, mapa de tracking                    | Google Maps Platform, Mapbox ou OpenStreetMap; qualidade de dados em Angola a validar                                                                        |
| Assinatura electrónica         | `dms`                      | 2–3     | Contratos, POD (proof of delivery), aceitação de cotações       | Fornecedor com validade legal em Angola; alternativa interina: assinatura desenhada + hash + audit log                                                       |
| Email transaccional (produção) | todos                      | 1 (dev) | Convites, recuperação de password, aprovações                   | Em dev usa-se Mailpit via SMTP; em produção configurar SMTP/SES/SendGrid via `SMTP_*`                                                                        |
| Câmbios oficiais               | `fin`                      | 3       | Importação automática de taxas BNA                              | Na Fase 1 as taxas são introduzidas manualmente (`exchange_rates`)                                                                                           |
| AGT / facturação electrónica   | `fin`                      | 3       | Validação de NIF e facturação certificada                       | Requisitos da Administração Geral Tributária                                                                                                                 |
| Antivírus no upload            | `dms`                      | 2–3     | Análise de ficheiros carregados antes de ficarem disponíveis    | ClamAV (sidecar) ou serviço gerido; hoje há validação de tipo por bytes iniciais, limite de 15 MB e download só como `attachment`                            |
| Alertas de validade agendados  | `dms` / `notifications`    | 2–3     | Notificar documentos a expirar (30 dias) por email/in-app       | Requer scheduler (cron/worker com Redis); hoje há filtro e contador no painel                                                                                |
| Telemática / GPS de frota      | `trk`                      | 4       | Posição em tempo real dos veículos                              | APIs dos fornecedores de telemática, app móvel do motorista                                                                                                  |
